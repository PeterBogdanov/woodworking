### 1. Архитектурное саммари проекта

#### 1.1 Математика и генерация геометрии в `generate_board.py`

- **Контур доски** формируется как `shapely.geometry.Polygon`, задается параметрами: длина, ширина, толщина, радиус скругления углов.
- **Карманы** — это множество `shapely.geometry.Polygon` или `shapely.geometry.MultiPolygon`, которые вырезаются из основной доски. Они могут быть:
  - Прямоугольными (с параметрами: ширина, длина, отступ от края),
  - Сотовыми — в виде сетки прямоугольников или других форм с заданным шагом.
- **Спиральные перегородки** генерируются как набор кругов или эллипсов, размещённых по спирали. Используются параметры: шаг спирали, радиус начального круга, количество витков.
- **Отступы и зазоры** определяются через параметры `tool_clearance` и `cut_depth`, чтобы избежать столкновений с инструментом.

#### 1.2 Генерация траекторий инструмента

- **Rough Pocketing (черновая фрезеровка)**:
  - Используется `shapely.ops.unary_union` для объединения всех карманов.
  - Построение траектории с шагом по глубине, с учётом `cut_depth`, `step_over`.
- **Finish (чистовая фрезеровка)**:
  - Применяется к внешнему контуру доски и внутренним карманам.
  - Используются `shapely.geometry.LineString` для построения профиля.
- **Profile Top / Profile Bottom Flip**:
  - Для верхней части: фрезеровка контура доски.
  - Для нижней части (FLIP): отражение геометрии по оси X/Y с учётом `flip_board` параметра.
  - Генерация траекторий строится по `shapely.geometry.Polygon.exterior`.

#### 1.3 Веб-сервер `serve.py`

- **Эндпоинты**:
  - `/generate` — принимает JSON с параметрами, вызывает `generate_board.generate()`, возвращает SVG.
  - `/gcode` — генерирует и возвращает G-код (в виде текста).
- **Генерация SVG на лету**:
  - Выполняется через `svgwrite` или `shapely` с использованием `render()` функций.
  - Кэширование SVG — через `hashlib` по параметрам запроса, чтобы не перегенерировать при повторных вызовах.
- **Вызов `generate_board`**:
  - В `serve.py` вызывается функция `generate_board.generate(params)` с передачей JSON-параметров.
  - Результат — объекты `shapely.geometry.Polygon`, `MultiPolygon`, которые обрабатываются для SVG и G-кода.

### 2. Четкая пошаговая процедура добавления новой формы доски или карманов

#### 2.1 Добавление новой формы доски (например, овальная)

**Место изменения:**
- В `generate_board.py` — в функции `generate_board()`:
  - Добавить новый параметр `board_shape` (например, `"rectangular"` или `"oval"`).
  - В зависимости от значения `board_shape`, генерировать `Polygon` с разными координатами.
    - Для овала: использовать `shapely.geometry.Polygon` с набором точек по эллипсу (например, через `numpy.linspace` и `math.cos/sin`).
  - Обновить `get_board_outline()` или создать новую функцию `create_oval_board()`.

**Контракт:**
- Функция должна возвращать `shapely.geometry.Polygon`.
- Параметры должны передаваться как словарь `params`.

#### 2.2 Добавление нового типа карманов (например, сотовых)

**Место изменения:**
- В `generate_board.py` — в функции `generate_pockets()`:
  - Добавить параметр `pocket_type` (`"rectangular"`, `"hexagonal"`, `"cellular"`).
  - Реализовать логику генерации сотовых карманов:
    - Создать сетку из прямоугольников/треугольников с заданным шагом.
    - Использовать `shapely.geometry.box()` или `shapely.geometry.Polygon` для создания ячеек.
  - Возвращать `shapely.geometry.MultiPolygon`.

**Контракт:**
- Функция должна возвращать `shapely.geometry.MultiPolygon`.
- Все параметры карманов должны передаваться через `params["pocket_params"]`.

#### 2.3 Учет G-кода и безопасных высот

**Для корректной генерации G-кода:**
- Убедиться, что:
  - `tool_clearance` учитывается при расчёте траекторий (для избегания столкновений).
  - При FLIP (перевороте заготовки) — корректно пересчитываются координаты Z и X/Y.
  - Используются безопасные высоты: `safe_z`, `start_z`, `cut_z`.
- В `generate_board.py`:
  - Проверить, что все `Polygon` и `MultiPolygon` корректно передаются в функции генерации G-кода.
  - При FLIP — вызывать `shapely.affinity.reflect()` или аналогичные операции для коррекции координат.

#### 2.4 Обновление `serve.py`

- В эндпоинте `/generate`:
  - Добавить новые параметры в JSON (например, `"board_shape": "oval"`).
  - Передать их в `generate_board.generate(params)` без изменений.
- Убедиться, что SVG и G-code генерируются корректно для новых форм.
