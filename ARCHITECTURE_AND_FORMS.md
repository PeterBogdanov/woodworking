# Анализ архитектуры board_v3 и добавление новых форм

Отчет подготовлен по результатам анализа проекта моделью `qwen3-coder:30b` (Ollama).

---

## 1. Архитектурное саммари проекта

### 1.1 Математика и геометрия в `generate_board.py`
- **Контур доски:** Представляется как `shapely.geometry.Polygon`. Формируется на основе базовых габаритов (диаметр/размеры, толщина, радиусы скругления).
- **Карманы (Pockets):** Набор полигонов (`shapely.geometry.Polygon` / `MultiPolygon`), вырезаемых из тела доски. Рассчитываются сектора/ячейки с учетом толщины перегородок (`WALL_W`), центральной ступицы (`HUB_R`) и внешнего бортика (`RIM_W`).
- **Спиральные / секторные перегородки:** Геометрия перегородок формируется с заданным углом закручивания (`SPIRAL_SWEEP`), шагом и радиусами скругления внутренних углов (`CORNER_F`).
- **Отступы и зазоры:** Контуры карманов офсетятся с помощью операций буферизации (`shapely.buffer`), учитывая диаметр рабочего инструмента и припуск на чистовую обработку.

### 1.2 Генерация траекторий инструмента (CAM / G-код)
- **01 — Rough Pockets (черновая выборка карманов):**
  - Объединение геометрии карманов через `shapely.ops.unary_union`.
  - Построение концентрических/параллельных траекторий (offsetting) с заданным шагом по глубине (`step_down`) и радиальным шагом (`step_over`).
- **02 — Finish Pockets (чистовая обработка дна и стенок):**
  - Контурная чистовая обработка фасонной/галтельной фрезой (bowl bit) для формирования радиусного перехода дно-стенка.
- **03a — Profile Top (обрезка контура сверху):**
  - Проход по внешнему периметру детали сверху с оставлением перемычек (tabs) или запаса под переворот.
- **03b — Profile Bottom FLIP (обработка снизу после переворота):**
  - Отражение координат по оси переворота (обычно X) с учетом базы заготовки (`BLANK_SIZE`), снятие фаски/галтели с тыльной стороны доски.

### 1.3 Веб-сервер `serve.py`
- **Эндпоинты:**
  - `/preview.svg` — принимает GET-параметры формы, динамически генерирует и возвращает SVG-вектор (с кэшированием по хэшу параметров).
  - `/generate` — запускает генерацию G-кода с текущими параметрами, проверяет коллизии и возвращает JSON со списком `.nc` файлов и отчетом.
  - `/layouts`, `/woods`, `/bits` — справочные данные о пресетах раскладок, режимах резания под породы дерева и параметрах инструмента.
- **Взаимодействие:** `serve.py` выступает легковесным контроллером, вызывающим расчетные функции `generate_board.py` и отдающим результаты в браузер.

## 2. Пошаговая процедура добавления новой формы

### Шаг 1. Определение геометрии в `generate_board.py`
1. **Функция генератора контура:**
   - Реализовать функцию построения новой формы (например, `create_oval_outline(...)` или `create_hex_pockets(...)`).
   - **Контракт:** Функция внешнего контура **обязана** возвращать замкнутый `shapely.geometry.Polygon` с центром в начале координат `(0, 0)`.
2. **Функция генератора карманов:**
   - **Контракт:** Должна возвращать список `[Polygon, ...]` или `MultiPolygon`, полностью лежащий внутри внешнего контура с отступом не менее `RIM_W`.
   - При скруглении углов карманов применять `buffer(-r).buffer(r)` с валидацией топологии (`is_valid`).

### Шаг 2. Интеграция в модуль CAM (траектории)
1. **Учет инструмента:**
   - Убедиться, что внутренние радиусы карманов не меньше радиуса фрезы чернового прохода (иначе фреза не войдет в углы).
2. **Операция FLIP (тыльная сторона):**
   - При добавлении несимметричной формы (например, овал или сложный многоугольник) проверить логику переворота заготовки: координата `X` инвертируется относительно центра стола/заготовки (`X_flipped = -X`).

### Шаг 3. Регистрация в `serve.py`
1. **Параметры и маршрутизация:**
   - Добавить идентификатор новой формы в допустимые параметры запроса (например, `layout_type="oval"` или `layout_type="honeycomb"`).
   - В обработчиках `/preview.svg` и `/generate` добавить ветвление вызова соответствующего генератора.
2. **Справочник раскладок:**
   - Добавить метаданные новой формы в список `/layouts` (название, дефолтные размеры, доступные диапазоны регуляторов).

### Шаг 4. Поддержка в интерфейсе (`interactive.html` / `texts.json`)
1. Добавить текстовые описания и подсказки для параметров новой формы в `texts.json`.
2. Добавить превью-иконку новой формы в галерею раскладок интерфейса.
