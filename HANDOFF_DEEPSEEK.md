# Раздача работы между dsh (DeepSeek) и Claude

dsh запускается так:

```bash
cd /Users/pb/Deepseek/snack_board/board_v3
npx @deepseek-ai/dsh web
```

Это полноценный агент с файлами и bash, а не чат: пастить файлы не нужно,
он сам читает каталог, правит код и запускает генератор.

Задания лежат в `tasks/`. Запускать по одному:

> Прочитай `tasks/00_ОБЩЕЕ.md`, потом выполни `tasks/A_ui.md`.

## Кому что

| задача | кому | почему |
|---|---|---|
| `tasks/A_ui.md` — интерфейс целиком | **dsh** | самый большой объём строк, нулевой риск для станка, проверяется глазами за минуту |
| `tasks/B_endpoints.md` — эндпоинты в serve.py | **dsh** | HTTP-обвязка, геометрии не касается |
| `tasks/C_texts.md` — описания пород и фрез | **dsh** | чистый текст, сверяется по паспортам фрез |
| Этап 1 — геометрия (`spiral_edge`, `Pocket.from_poly`, фикс `raster`) | **Claude** | час работы, и это единственное место, где ошибка идёт не в тест, а в заготовку |
| Этап 2 — привязка операций к ролям фрез | **Claude** | трогает `op_rough/op_finish/op_profile` |
| Финальная приёмка | **Claude** | |

A, B и C независимы — можно пустить подряд, не дожидаясь геометрии.
B специально написана так, чтобы работать при ещё не существующих
`G.LAYOUTS/G.BITS` (отдаёт пустой список).

## Почему геометрию всё же можно было бы отдать — и почему не отдаём

Приёмка в проекте сильная: `report.txt` ловит и нарушение зазоров, и дыру в
траектории (дырку в центре от неверного `rmin` он бы поймал как
«!!! ДЫРА В ТРАЕКТОРИИ»). Но эту проверку можно удовлетворить и вырожденной
геометрией — сделать карманы мельче, и всё «сойдётся». Отчёт не знает, как
изделие должно выглядеть. Поэтому раскладки пишу я, а отчёт остаётся
последним рубежом, а не единственным.

## Как проверяю за ним

Проект теперь под git, базовый коммит сделан. Основной инструмент ревью:

```bash
git diff --stat      # что вообще тронуто
git diff             # что именно
```

На что смотреть конкретно:

* **Вышел за задачу.** Любимое поведение — «заодно улучшить» соседний код.
  В `git diff --stat` должны быть только файлы из задачи.
* **Задача B — обход каталога.** `/nc/<имя>` пускает имя из браузера в
  файловую систему. Проверить `curl 'http://127.0.0.1:8000/nc/../../etc/passwd'`.
* **Задача B — не подкрутил ли проверки.** `git diff generate_board.py`:
  изменения порогов в `coverage_check`, `WALL_ALLOW`, `CORNER_F` или в линтере
  `check_nc` — это не починка, это глушение сигнализации.
* **Задача C — выдумки про фрезы.** Модели любят приписать 1372 или 1406
  наружный roundover кромки. Они его не делают.
* **Всегда в конце:** `python3 generate_board.py` → «ГЕОМЕТРИЯ И ТРАЕКТОРИИ В ПОРЯДКЕ».
