# Общие правила для всех задач (dsh)

Рабочий каталог: `/Users/pb/Deepseek/snack_board/board_v3` — **только он**.

## Красные линии

* **Не трогай `/Users/pb/Deepseek/snack_board/generate_board.py`** (в корне) —
  это старая дюймовая версия, она к делу не относится. Каталоги `variant-1`,
  `variant-2` — тоже архив, не трогать.
* **Не меняй геометрию** в `board_v3/generate_board.py`, если задача явно этого
  не требует: функции `spiral_edge`, `Pocket`, `build_pockets`, `contour_runs`,
  `cut_raster`, `cut_contour`, `op_*`, `coverage_check`. Это траектории фрезы по
  реальному станку; ошибка тут ломает заготовку, а не тест.
* Никаких новых зависимостей: только стандартная библиотека python3.
  Никаких npm, CDN, внешних шрифтов — всё работает офлайн.
* Не переформатируй файлы целиком и не переименовывай существующие функции.
  Правки точечные.

## Приёмка

Проект под git. Перед сдачей покажи `git diff --stat` — в нём не должно быть
файлов, которые задача менять не просила.

Главный тест проекта — он же приёмка для всего, что касается python:

```bash
python3 /Users/pb/Deepseek/snack_board/board_v3/generate_board.py
```

Считается минуту. В конце `report.txt` должна быть строка
**«ИТОГ: ГЕОМЕТРИЯ И ТРАЕКТОРИИ В ПОРЯДКЕ»** и чистый линтер по всем `.nc`.
Если там «ЕСТЬ ЗАМЕЧАНИЯ» — работа не сдана, разбирайся, а не подкручивай
пороги проверок.

Контекст проекта целиком — в `../PLAN.md`. Прочитай его первым делом.

## Контракт эндпоинтов (общий для задач A и B)

```
GET /layouts  -> [{id, title, n_pockets, center, defaults:{...}}]
GET /woods    -> [{id, title, janka, scale, rpm, dial, note}]
GET /bits     -> [{id, title, role, dia, rpm, rpm_max, loc,
                   feed, plunge, doc, stepover, color, op_file, note}]
                 role: rough | bowl | profile | surface

GET /preview.svg?<параметры>             форма, быстро (<0.1 с)
GET /paths.svg?bits=em,bowl&<параметры>  траектории выбранных фрез (4-5 с)
GET /generate?<параметры>                -> {ok, report, files:[{name,size,minutes,url}]}
GET /nc/<имя>.nc,  GET /nc.zip           скачивание
```

Параметры формы: `layout, BOARD_DIA, THICK, POCKET_DEPTH, RIM_W, N_POCKETS,
SPIRAL_SWEEP, HUB_R, WALL_W, CORNER_F, BLANK_SIZE, BLANK_THICK, WOOD`.
Все размеры — миллиметры.
