# Задача B — эндпоинты в `serve.py`

Сначала прочитай `00_ОБЩЕЕ.md` и `../PLAN.md`.

`board_v3/serve.py` — 76 строк, `http.server.BaseHTTPRequestHandler`. Добавь
эндпоинты из контракта в `00_ОБЩЕЕ.md`, сохранив стиль файла (метод `_send`,
тихий `log_message`, без зависимостей).

## Источники данных

Из модуля `generate_board` (импортирован как `G`): `G.LAYOUTS`, `G.WOODS`,
`G.BITS`. **Если каких-то из них ещё нет — не выдумывай и не создавай их в
`generate_board.py`.** Сделай эндпоинт, читающий их через `getattr(G, ..., None)`,
и возвращающий пустой список, если структуры пока нет. Их добавит отдельная задача.

## Детали

* `/nc.zip` — через `zipfile` в память из каталога `nc/`.
* `/nc/<имя>` — отдавать только `.nc` из каталога `nc/`. Имя обязательно
  прогнать через `os.path.basename`, чтобы `../` не вышел за каталог.
  Это трогает файловую систему по запросу из браузера — проверь на
  `/nc/../../etc/passwd`, должно быть 404, а не файл.
* `/generate` — теперь возвращает JSON `{ok, report, files:[{name,size,minutes,url}]}`,
  а не голый текст. `ok` — по наличию строки «В ПОРЯДКЕ» в отчёте.
* `/paths.svg?bits=em,bowl` — рисует траектории только выбранных фрез. Механика
  уже есть: пути помечены тегами `rough / finish / profile` в `main()`
  (`generate_board.py:1327-1338`), `svg_preview` (`:1027`) красит по тегу.
  Нужен фильтр по списку из query. Если для этого нужна функция в
  `generate_board.py` — добавь **новую**, не меняя существующие.
* Исключения не должны утекать в ответ трейсбеком наружу — коротко и в лог.

## Приёмка

`python3 generate_board.py` по-прежнему даёт «В ПОРЯДКЕ». Каждый эндпоинт
проверить curl'ом, включая попытку обхода каталога. В `git diff --stat` —
`serve.py` и, если понадобилось, добавленные (не изменённые) функции в
`generate_board.py`.
