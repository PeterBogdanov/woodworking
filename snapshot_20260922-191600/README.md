# boardcam — G-code для деревянных досок из OpenSCAD

Форму задаёте в **OpenSCAD** (панель Customizer, сохраняете набор параметров), а **boardcam**
сам выбирает фрезы из вашей библиотеки, строит траектории, проверяет их и пишет файлы `.nc`
для **MASSO G3** (Onefinity Elite 2 Woodworker, Makita RT0701C). Всё в миллиметрах, всё
офлайн: Python 3.11+ без сторонних пакетов плюс установленный OpenSCAD.

## Установка

1. Python 3.11+.
2. OpenSCAD — лучше свежий снапшот (быстрый бэкенд Manifold):
   `brew install --cask openscad@snapshot` (macOS) или пакет/AppImage с openscad.org.
   Если исполняемый файл не в PATH и не в `/Applications`, укажите его:
   `export BOARDCAM_OPENSCAD=/путь/к/openscad`.
3. Проверка: `python3 -m boardcam doctor`.

## Как работать

1. **Форма.** Откройте `shapes/pinwheel.scad` (вертушка) или `shapes/tray.scad` (поднос) в
   OpenSCAD, Window → Customizer, покрутите параметры, посмотрите 3-D (F5), нажмите «+»
   и сохраните набор параметров — он попадёт в `shapes/<форма>.json`. Это и есть файл дизайна.
2. **Задание.** `jobs/<имя>.json`: форма, имя набора, материал, при желании — своя фреза на роль:

   ```json
   {"schema": 1, "name": "spiral-3-maple", "shape": "pinwheel", "preset": "spiral-3",
    "overrides": {}, "material": "maple", "tools": {}, "options": {"flatten": "auto", "profile_mode": "auto"}}
   ```

3. **Генерация.** `python3 -m boardcam generate jobs/spiral-3-maple.json` → каталог
   `out/spiral-3-maple/<дата-время>/` с `nc/*.nc`, `report.txt`, `job_sheet.md`, `preview.svg`,
   `model.stl`, `machined.bin`, `design.json`, `run.zip`.
   Если в конце отчёта не **«ИТОГ: ГЕОМЕТРИЯ И ТРАЕКТОРИИ В ПОРЯДКЕ»** — на станок не нести.
   Если фрезы не подходят, вместо файлов будет список отказов простыми словами
   (`python3 -m boardcam plan …` показывает то же без генерации).
4. **Страница.** `python3 -m boardcam serve` → http://127.0.0.1:8000 — задания, библиотека фрез и
   материалов, прогоны с отчётом и 3-D просмотром (модель, обработанная поверхность, заготовка).

## Что проверяется

- зазоры каждой траектории до стенок (черновая по уровням, чистовая, контур снаружи детали);
- **карта высот**: STL из OpenSCAD против того, что оставят фрезы (плоская, чашечная, шаровая) —
  зарез глубже 0.1 мм роняет вердикт, недоснятые места перечисляются с площадью и глубиной;
- линтер готовых `.nc`: рапиды в материале, выход за заготовку, глубина, подача.

Порядок на станке — в `job_sheet.md` каждого прогона: ноль в левом ближнем углу заготовки,
Z0 — верх заготовки, файлы по очереди, переворот вокруг оси X для нижнего контура, табы.

## Библиотека

`data/tools.json`, `data/materials.json`, `data/machine.json` — ваши фрезы, породы и станок.
Редактируются на странице, командой `python3 -m boardcam library …` или руками. Запись,
на которую ссылается задание, удалить нельзя.

## Второй вход: голый STL

`python3 -m boardcam build --stl деталь.stl` или задание с `"mesh": "путь/деталь.stl"`
восстанавливает карманы из сетки (карта высот → уровни → контуры). Точность ниже
(контуры ±1 мм, у стенок остаётся полоса под ручную доводку), каждое допущение печатается.

Подробности для разработки — `DESIGN.md`, `IMPLEMENTATION.md`, `docs/`.
