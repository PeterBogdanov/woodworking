# Задача A — интерфейс `interactive.html`

Сначала прочитай `00_ОБЩЕЕ.md` и `../PLAN.md`.

Перепиши `board_v3/interactive.html`. Один файл, ванильный JS, без сборщиков,
без npm, без CDN — файл отдаётся локальным python-сервером и должен работать
офлайн. Сейчас там 10 ползунков и превью; нужно добавить галерею раскладок,
выбор породы и выбор фрез.

Эндпоинты — в `00_ОБЩЕЕ.md`. Не выдумывай свои пути. Их серверную часть делает
задача B; пока её нет, интерфейс должен не падать, а показывать ошибку текстом.

## Что должно быть

1. **Галерея раскладок.** Грузишь `/layouts`, рисуешь плитки; картинка плитки —
   `<img src="/preview.svg?layout=ID">`. Клик выбирает раскладку и подставляет
   её `defaults` в ползунки.
2. **Ползунки параметров** — как сейчас, плюс число отсеков `N_POCKETS`.
   Значение числом рядом, единицы — миллиметры. При изменении перерисовывать
   `/preview.svg` с задержкой 150 мс.
3. **Порода.** Выпадающий список из `/woods`. При выборе — карточка: твёрдость
   Janka, множитель подач, обороты, положение регулятора Makita RT0701C, `note`.
4. **Фрезы.** Список из `/bits` с чекбоксами. У каждой: диаметр, обороты,
   подача, глубина за проход, `note`, цветной квадрат `color`. Галки управляют
   `/paths.svg?bits=...` — траектории выбранных фрез поверх формы. Есть
   «выбрать все» — сводная картина, что делают все фрезы вместе.
   `/paths.svg` считается 4–5 секунд: спиннер, и не слать новый запрос, пока не
   пришёл предыдущий.
5. **Кнопка «Сгенерировать G-code».** Запрос блокирующий, до минуты: заблокировать
   кнопку, спиннер, надпись «идёт расчёт, до минуты». По ответу — `report`
   моноширинным текстом, список файлов со ссылками и ссылка на `/nc.zip`.
   Если в отчёте «ЕСТЬ ЗАМЕЧАНИЯ» — красная плашка «НА СТАНОК НЕ НЕСТИ».
   Если «В ПОРЯДКЕ» — зелёная.

## Требования

Каждый `fetch` в try/catch, ошибка видна текстом, а не молчанием. Интерфейс
на русском. Тёмная и светлая тема через `prefers-color-scheme`. Работает от
380 px ширины. Комментарии в коде по-русски.

## Приёмка

`python3 serve.py`, открыть `http://127.0.0.1:8000/`, проверить своими глазами:
ползунки двигают превью, спиннеры работают, повторные клики не шлют лавину
запросов. В `git diff --stat` — только `interactive.html`.
