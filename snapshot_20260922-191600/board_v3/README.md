# Менажница-«вертушка» — генератор G-code · v3.1-mm

Под **Onefinity Elite 2 Woodworker + MASSO G3 + Makita RT0701C**.
**Всё метрическое: G21, размеры в миллиметрах, подачи в мм/мин.**

```bash
python3 generate_board.py     # -> nc/*.nc, report.txt, preview.png, preview.svg
python3 serve.py              # http://127.0.0.1:8000 — ползунки, живое превью, кнопка генерации
```

Скрипт сам себя проверяет: геометрия, зазоры фрезы, покрытие дна, плюс **линтер
готовых .nc** (рапиды в материале, выход за заготовку, перебор по глубине; у линтера
есть самопроверка на заведомо плохом файле). Если в конце `report.txt` не написано
«ГЕОМЕТРИЯ И ТРАЕКТОРИИ В ПОРЯДКЕ» — на станок не нести.

## Версии

| версия | что |
|---|---|
| 3.0 | угловой ноль, квадратная заготовка, исправления траекторий (см. таблицу внизу), дюймы |
| **3.1-mm** | метрика (G21, мм, мм/мин), задаётся размер **и толщина заготовки**, торцовка снимает излишек послойно, версия печатается в шапке каждого .nc, в отчёте и в UI |

## Заготовка и ноль

* Заготовка — **квадрат `BLANK_SIZE` × `BLANK_SIZE` × `BLANK_THICK`** (430 × 430 × 25 мм),
  доска центрирована в ней.
* **X0 Y0 = левый ближний угол заготовки** (`ORIGIN='corner'`). Центр доски печатается
  в `report.txt` (для 430 мм это X215 Y215).
* **Z0 = верх заготовки.**
* `BLANK_THICK > THICK` — излишек снимает файл 00 (`FLATTEN=True`, нужна торцовочная фреза),
  послойно по `doc`. **После торцовки Z обнулить заново** по новой плоскости.
  Если `FLATTEN=False`, скрипт предупредит и будет резать контур на всю толщину заготовки.
* Квадрат важен для переворота: доска центрирована, поэтому после переворота вокруг
  любой оси окружность попадает на то же место — достаточно снова обнулиться в углу.

## Что крутить (всё в мм)

| параметр | по умолчанию | что делает |
|---|---|---|
| `BLANK_SIZE` / `BLANK_THICK` | 430 / 25 | **исходная заготовка** |
| `BOARD_DIA` | 406.4 | диаметр изделия (это ровно 16") |
| `THICK` | 25 | **высота готовой доски** |
| `POCKET_DEPTH` | 12 | глубина отсеков, максимум 15.8 (режущая часть Whiteside 1372) |
| `RIM_W` | 25 | ширина бортика |
| `SPIRAL_SWEEP` | 200° | закрутка вертушки |
| `HUB_R` / `WALL_W` / `CORNER_F` | 30 / 12 / 14 | втулка, толщина стенки, скругления в плане |
| `WOOD` | maple | порода — масштабирует подачи (`walnut`, `oak`, `jatoba`, `soft`, …) |

`CORNER_F` должен быть больше радиуса фрезы 1372 (9.53 мм), иначе внутренние углы
она не выберет. Те же параметры — ползунками в `serve.py`.

## Порядок работы

1. *(опционально)* **00_flatten_top_OPTIONAL.nc** — торцовка, снимает `BLANK_THICK − THICK`.
   После неё **переобнулить Z**.
2. **01_rough_pockets_MollyMill.nc** — Molly Mill D6.35, черновая выборка трёх отсеков,
   припуск 0.6 мм на стенки и дно.
3. **02_finish_pockets_1372_bowl.nc** — Whiteside 1372, стенки + дно за один проход по Z,
   фреза сама даёт R6.35 в углу «стенка-дно».
4. **03a_profile_top.nc** → переворот → **03b_profile_bottom_FLIP.nc** — контур.
   После переворота **обнулить Z по новой верхней плоскости**, X/Y — снова в углу.
   Табы (5 × 23 мм) держат деталь на последнем проходе 03b.

Если вписать в `TOOL_PROFILE['loc']` реальную длину режущей части ≥ THICK + 1.2,
скрипт соберёт один файл `03_profile_full.nc` вместо пары 03a/03b (`PROFILE_MODE='auto'`).

Ориентир по времени при дефолтных параметрах: черновая ~41 мин, чистовая ~7, контур ~11.

## Что ОБЯЗАТЕЛЬНО проверить перед первым запуском

* **`loc` у фрез** (длина режущей части) — измерьте штангенем и впишите в `TOOL_*`.
  По Molly Mill производитель даёт только диаметр 6.35 мм; в коде стоят консервативные 19 мм.
* **Обороты.** `dial_for()` переводит RPM в положение регулятора Makita по замерам
  тахометром (`rpm ≈ 5000·dial + 2000`). Проверьте своим тахометром, при
  расхождении поправьте `DIAL_K / DIAL_B`.
* Подачи в `TOOL_*` — стартовые для твёрдого клёна. Первый прогон — с рукой на паузе.

## Чего этот набор НЕ делает

* **Скругления наружной кромки нет.** Ни 1372 (bowl & tray), ни 1406 (round nose)
  наружный roundover сделать не могут — у них плоское/вогнутое дно, они просто
  срежут бортик. Кромку — ручным фрезером с кромочной фрезой или шлифовкой.
* **Острые «рожки» отсеков у бортика и у втулки** фреза не выбирает — туда не влезает
  ни D19, ни D6.35. Там дерево остаётся, стенка плавно сливается с бортиком.
  Количество таких узлов печатается в `report.txt` (КОНТРОЛЬ ПОКРЫТИЯ).
* **Жёлоб (1406)** выключен, требует бортика ≥ 32 мм: `JUICE_GROOVE=True`.
* `"Jenny" 3/8"` — хвостовик 9.53 мм, в штатную цангу RT0701C (6.35) не влезет, нужна
  цанга Makita 763637-1. Заготовка под неё — закомментированный `TOOL_PROFILE` в коде.
