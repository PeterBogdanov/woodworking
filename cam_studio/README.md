# CamStudio — Next-Gen Woodworking CNC CAM

Автономное приложение нового поколения для генерации высококачественного G-кода для деревообработки на ЧПУ станках (Onefinity Elite 2 с ЧПУ MASSO G3 Touch и фрезером Makita RT0701C).

Создано в отдельном каталоге `cam_studio/` без изменения существующего приложения `boardcam/`.

---

## 🪵 Внедренные Best Practices для обработки древесины

### 1. Grain-Aware Toolpaths (Ориентация по направлению волокон)
* **Проблема:** В древесине (особенно орех, клен, ясень) фрезерование поперек волокон на выходе зуба вызывает задиры и сколы (tear-out).
* **Решение в CamStudio:** Интерактивный угол волокон (0°..180°). Чистовые проходы кармана ориентируются строго вдоль волокон древесины.
* **Режим Climb Milling (Попутное резание):** Все режущие ходы выполняются в одном направлении (толстая часть стружки на входе, нулевая на выходе), что прижимает волокна к заготовке и дает зеркальную поверхность.

### 2. Helical Ramp Entry (Винтовое врезание по спирали)
* **Проблема:** Прямой удар фрезы вниз (plunge) перегружает шпиндель, а на торце фрезы скорость резания равна 0, что вызывает прижоги дерева (burn marks).
* **Решение:** Фреза входит по спирали (G2 с уменьшением Z на 1 мм за оборот) на рабочей подаче, заканчивая полный чистящий круг на дне.

### 3. Smooth 3D Ramp Tabs (Треугольные мостики без остановки станка)
* **Проблема:** Обычные прямоугольные мостики заставляют станок тормозить, подниматься по Z, ехать по X/Y и опускаться, оставляя ступеньки и следы вибрации.
* **Решение:** Треугольные мостики с непрерывной интерполяцией $Z(s)$ по длине периметра. Станок проходит мостики плавно на полной рабочей подаче без остановки.

### 4. Chip Load & Speeds/Feeds Calculator (Контроль стружки и прижога)
* **Формулы:**
  $$\text{Chip Load } c_z = \frac{F}{\text{RPM} \times \text{flutes}}$$
  $$\text{Feed } F = \text{RPM} \times \text{flutes} \times c_z$$
  $$\text{Cutting Speed } V_c = \frac{\pi \times D \times \text{RPM}}{1000}$$
* **Защита от прижога:** При $c_z < 0.035$ мм/зуб система выдает предупреждение о риске перегрева и прижога волокон.
* **Makita RT0701C Dial Advisor:** Рекомендация положения колесика регулятора оборотов (1..6) для ручного фрезера.

### 5. Интерактивный 3D WebGL симулятор
* Вращение (ЛКМ), масштабирование (колесико мыши) и сдвиг (Shift + ЛКМ).
* Цветовая дифференциация: синий — проходы по волокнам, зеленый — спиральный вход, янтарный — 3D мостики контура.
* Вкладка просмотра готового G-кода с кнопкой прямого скачивания `.nc` файла для стойки Masso G3.
