# План развития boardcam

## Выполнено
- [x] **Восстановление библиотеки**: подключены инструменты (`data/tools.json`), материалы ценных пород (`data/materials.json`), конфигурация станка Onefinity Elite 2 с MASSO G3 Touch (`data/machine.json`), формы OpenSCAD и тестовые задания.
- [x] **Модуль торцовки (surfacing)**: CLI-утилита `boardcam.surface` для выравнивания прямоугольной заготовки змейкой со слоями и перекрытием.
- [x] **Безопасный постпроцессор MASSO G3 + Makita RT0701C**:
  - Предварительный подъём на безопасную высоту `z_safe` (из `machine.json`, по умолчанию 9 мм).
  - Предупреждение оператору `( MSG: ПРОВЕРЬТЕ ШПИНДЕЛЬ: Makita RT0701C ДИСК ~X, S... )`.
  - Задержка `G4 P3.0` (3 секунды) после команды `M03` для гарантированного набора оборотов ручным фрезером до врезания.
  - Повторный контроль высоты `z_safe`.
